# Crédits photographiques

Toutes les photographies du site viennent de Wikimedia Commons et sont utilisées sous leur licence libre. Elles
illustrent la vie étudiante dans des universités d'Afrique ; aucune ne représente un partenaire, un utilisateur ou un
membre de CAMPUUS. Les crédits sont aussi affichés dans le pied de page du site (« Crédits photographiques ») et
régénérés dans `src/content/photos.ts` par `node tools/fetch-photos.mjs`, qui télécharge et convertit les fichiers en
WebP dans `public/photos/`.
